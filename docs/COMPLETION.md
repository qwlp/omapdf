# Feature tracking

Omapdf's outstanding work is tracked as TODOs in [ROADMAP.md](ROADMAP.md).
Implemented features are described in [README.md](../README.md); supported
commands are listed in [COMMANDS.md](COMMANDS.md).

Application changes must be checked, built, packaged and installed according to
[AGENTS.md](../AGENTS.md). Preserve existing documents, library data and running
reader processes. Desktop tests use isolated configuration and library files.
